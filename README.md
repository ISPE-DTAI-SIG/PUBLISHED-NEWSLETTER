# ISPE DTAI SIG Newsletter

Quarterly newsletter for the ISPE Digital Technology and Artificial Intelligence Special Interest Group (DTAI SIG), published via GitHub Pages.

## Live site

- **Latest issue:** https://ispe-dtai-sig.github.io/PUBLISHED-NEWSLETTER/
- **Q2 2026 (archive):** https://ispe-dtai-sig.github.io/PUBLISHED-NEWSLETTER/q2-2026/

## Structure

- `index.html` — the current/latest issue (currently Q2 2026)
- `q2-2026/index.html` — permanent archived copy of the Q2 2026 issue

Each newsletter is a single self-contained HTML file (images embedded as data URIs). To publish a new issue, add it under a dated folder (e.g. `q3-2026/`) and update the root `index.html`.

## Updating the newsletter

See [Updating the newsletter](UPDATING-NEWSLETTER.md) for step-by-step instructions, a reusable ChatGPT or Claude prompt, a review checklist, and publishing steps. No AI connection to GitHub is required.
